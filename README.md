## 🛠️ Technologies

## 📌 Project Overview

This project is a responsive website created for a salad bar and cafe.

The website is designed to provide a clean and accessible menu experience across desktop, tablet, and mobile devices.

* Creating the user interface
* Implementing responsive layouts
* Developing interactive elements with JavaScript
* Styling and structuring the website
* Testing the website on different screen sizes
